# HDRI Environment Maps

## Download FREE HDRI

Get high-quality HDRI dari:

1. **Poly Haven** (https://polyhaven.com/hdris)
   - Best quality, completely free
   - Search: "snowy", "winter", "arctic", "overcast"
   - Download 2K or 4K `.hdr` format

2. **HDRI Haven** (https://hdrihaven.com/)
   - Winter/arctic environments
   - Download `.hdr` format

## Recommended HDRI for Arctic Scene:

- **kloppenheim_06** (snowy forest)
- **snowy_forest** (winter scene)
- **alps_field** (mountain environment)
- **winter_evening** (cold atmosphere)

## How to Use:

1. Download `.hdr` file
2. Rename to `arctic_env.hdr`
3. Place in this folder (`/public/hdri/`)
4. Restart dev server

## Alternative (If no HDRI):
The scene will use procedural gradient background as fallback.

## File Size:
- 2K HDR: ~5-10MB (recommended)
- 4K HDR: ~20-40MB (best quality)
