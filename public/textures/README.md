# Textures Guide

## Ice Textures

Download FREE ice/frost textures dari:

1. **Poly Haven** (https://polyhaven.com/textures)
   - Search: "ice", "frost", "snow"
   - Download 2K resolution
   - Get: Color, Normal, Roughness maps

2. **CC0 Textures** (https://cc0textures.com/)
   - Search: "ice", "snow", "frost"
   - Download PBR set

3. **Texture Haven** (https://texturehaven.com/)
   - Arctic/winter themed textures

## Recommended Textures:

### For Ice Blocks:
- `ice_color.jpg` - Albedo/color map
- `ice_normal.jpg` - Normal map (surface detail)
- `ice_roughness.jpg` - Roughness map
- `ice_ao.jpg` - Ambient occlusion (optional)

### For Ground:
- `snow_color.jpg`
- `snow_normal.jpg`
- `snow_roughness.jpg`

## How to Use:

1. Download textures
2. Place in this folder (`/public/textures/`)
3. Restart dev server
4. Textures will auto-load

## File Naming:
- Use exactly these names for auto-detection
- Or update TextureLoader.js with your filenames
